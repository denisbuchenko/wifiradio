# Рядом — Wi-Fi рация для двоих

Маленькая программа для Windows 10/11 x64 на Rust. Работает через ваш роутер, без сервера, регистрации и интернета. Wi-Fi и сетевой кабель можно сочетать.

## Как начать

1. Скопируйте **один и тот же** `dist/WifiRadio-0.3.0.exe` на оба компьютера. Выберите постоянную папку: автозапуск ссылается на этот файл. В сборке также есть идентичный `WifiRadio.exe`.
2. Запустите файл на обоих компьютерах, подключённых к одному роутеру.
3. Если Windows спросит о доступе к сети, разрешите **частные сети**. Для связи нужен входящий UDP-порт **49735**. Программа сама не меняет брандмауэр.
4. Дождитесь жёлтой кнопки. Держите её мышью или удерживайте пробел. Говорите после надписи «Говорите». Отпустите кнопку, чтобы услышать ответ.

Серая кнопка означает, что вторая рация пока не найдена. Жёлтая — другая программа запущена и доступна, даже если её окно спрятано в трей. Во время входящей речи кнопка показывает «Слушаем»: это рация, вы говорите по очереди.

После трёх минут без передачи голоса, а также перед первым разговором, обе стороны слышат три коротких мягких тона одной гаммы: до, ми, соль. До окончания тонов микрофон не записывает. Продолжайте держать кнопку, дождитесь «Говорите», затем начинайте фразу.

Микрофон закрывается при отпускании кнопки или пробела, потере фокуса, закрытии окна и разрыве связи. Звук нигде не сохраняется. Программа использует выбранные в Windows микрофон и динамики; после смены устройства отпустите кнопку и начните заново. При смене динамиков перезапустите программу.

## Трей и автозапуск

Крестик полностью завершает программу. Сворачивание и Escape оставляют её на панели задач; при этом рация продолжает слушать. Для фонового режима выберите `⋯ → Убрать в трей`. Значок находится рядом с часами, в том числе под стрелкой скрытых значков. Щелчок открывает окно, правый щелчок — меню. Если Windows не принимает значок, приложение остаётся доступным на панели задач.

Повторный запуск того же `.exe` возвращает окно уже работающей рации. Версия показана в заголовке. `⋯ → Перезапустить рацию` закрывает старый экземпляр и запускает новый.

Для обновления запустите файл с новым именем `WifiRadio-0.3.0.exe`: не нужно перезаписывать работающий старый `.exe`. Новый файл сам закрывает предыдущие версии этой рации. Он также освобождает UDP-порт, если его удерживает старая копия без окна. Восстановление ограничено процессами с именем этой программы; чужие приложения оно не завершает. При ошибке появляется сообщение, а не молчаливый выход.

Меню `⋯` содержит фоновый режим, подключение по IP, автозапуск, подсказку, перезапуск и выход. Автозапуск включается при первом обычном запуске файла. Права администратора не нужны: используется `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, значение `WifiRadio`, с параметром `--background`. Состояние первого запуска хранится рядом с `.exe` в файле `wifiradio.initialized`. Отключение через меню или настройки Windows сохраняется. При обновлении в той же папке включённый автозапуск получает путь к новому файлу.

Перед перемещением или удалением `.exe` выключите автозапуск в меню. Чтобы полностью остановить программу, выберите «Выход».

## Если связь не появилась

- Проверьте, что на обоих компьютерах запущен тот же `.exe`, а не две независимые сборки.
- Подождите около десяти секунд: кроме широковещательного поиска программа пробует прямой поиск устройств в ближайшем участке локальной сети.
- Откройте `⋯ → Подключение` на обоих ПК. Вверху показан IP Wi-Fi/Ethernet этого компьютера. Введите адрес второго ПК в поле первого и нажмите «Подключить». На втором можно оставить автопоиск или указать адрес первого. Не вводите IP VPN. Для возврата к автопоиску очистите поле и нажмите «Подключить». Настройка сохраняется рядом с `.exe` в `wifiradio.peer`.
- Оба компьютера должны видеть друг друга в локальной сети. В гостевой Wi-Fi сети роутер часто запрещает связь между устройствами.
- Проверьте разрешение приложения в брандмауэре и сетевой профиль «Частная сеть» именно домашнего Wi-Fi/Ethernet.
- VPN могут быть разных марок. Программа выбирает физический адаптер и направляет локальные пакеты через него. Но запрет локальной сети или Kill Switch внутри VPN всё ещё может блокировать связь. Разрешите доступ к локальной сети в VPN или исключите `WifiRadio.exe` из VPN на обоих ПК. В Amnezia для Windows используйте [раздельное туннелирование по приложениям](https://docs.amnezia.org/documentation/instructions/vpn-split-tunneling/) и режим исключений, чтобы рация работала без VPN. Программа сама не меняет VPN, маршруты и правила брандмауэра.
- Окно «Подключение» показывает отправленные и полученные пакеты, число сообщений от второй рации и последнюю ошибку отправки. Полученные пакеты могут включать собственные широковещательные сообщения: это ещё не подтверждает связь с другим ПК.
- Проверьте доступ настольных приложений к микрофону: «Параметры Windows → Конфиденциальность и безопасность → Микрофон». Выберите рабочие устройства ввода и вывода в настройках звука Windows.
- После отключения второго компьютера кнопка станет серой примерно через пять секунд. После восстановления сети устройства найдут друг друга снова.
- Ошибки запуска, восстановление старых копий и завершение отмечаются в `wifiradio.log` рядом с `.exe`. Предыдущая часть журнала — `wifiradio.previous.log`. Голос и ключ пары в журнал не записываются. Журнал помогает выяснить сбой второго ПК; локальные отчёты не следует публиковать без необходимости.

## Приватная пара

Сетевые сообщения, включая голос и поиск устройств, защищены XChaCha20-Poly1305. При первой сборке создаётся случайный ключ `.local/room.key`, который встраивается в `.exe`. Поэтому проще всего передать девушке копию этого `.exe`: вводить код не нужно.

Кто получит этот же файл или ключ, сможет присоединиться к этой паре. Не публикуйте личную сборку для посторонних. Это простая рация на два устройства; третий участник не поддерживается. Удаление ключа создаст новую пару при следующей сборке. Сохраните ключ для совместимых обновлений, не добавляя его в Git.

## Сборка

На этой машине Rust и кеши установлены только в `.tools` внутри проекта. Для нового checkout:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/bootstrap-rust.ps1
powershell -ExecutionPolicy Bypass -File scripts/build.ps1 -Check
```

С готовым Rust достаточно второй команды. Результат: `dist/WifiRadio.exe`, инструкция и SHA-256. Никаких DLL рядом с файлом не требуется. Сборка использует GNU toolchain; подходит и установленный MSVC Rust с C++ Build Tools. Приложение пока не подписано сертификатом издателя.

Параметр `--no-autostart` запускает обычное окно без записи настроек автозапуска. Параметр `--self-test <report-path>` проверяет обмен синтетическим звуком через два настоящих UDP-сокета на loopback; он не открывает микрофон, не выводит звук и не меняет реестр.

Параметр `--restart` перезапускает уже работающую рацию. Без него новый запуск возвращает окно исправного экземпляра. Запуск с `--background` прячет только первый экземпляр и только при доступном значке трея.

Параметр `--diagnostics <report-path>` записывает версию, выбранные LAN-адреса, рассчитанные broadcast-адреса и результат привязки сокета к адаптеру. Он не запускает рацию и не меняет микрофон, VPN, брандмауэр или автозапуск. Отчёт содержит локальные IP; не публикуйте его без необходимости.

Архитектура и протокол описаны в [docs/architecture.md](docs/architecture.md). Проверки и их ограничения — в [docs/testing.md](docs/testing.md).
